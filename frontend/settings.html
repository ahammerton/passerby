Backup & restore

Save everything on this page to a file, for example before moving the app to another machine, and load it back later. Restoring replaces the current settings and applies them straight away.

Admin password

Set ADMIN_PASSWORD in the server's .env so only you can change settings. It can't be set here, so a typo can't lock you out.

Home location

Click the map or drag the marker to set where everything is measured from.

Aircraft

Your ADS-B receiver

A receiver on your own network (for example a Flightradar24 or FlightAware feeder) gives the freshest positions, every couple of seconds. Enter its IP address and the app finds its aircraft data.

Either way, your receiver's data is used for every aircraft it can see.

OpenSky Network

Optional: an API client lets OpenSky be polled every 30 s instead of every 4 min. Create one on your OpenSky account page.

The file OpenSky gives you when you create an API client. It's read in your browser; nothing is uploaded until you press Save.

Saved keys and passwords are never shown again: leave the box empty to keep the current one, or type a new one to replace it. New ones are checked before they're saved.

Trains

Trains are off: enter your Network Rail login under “Login” below to turn them on. These settings are saved for when they are.

Departure boards

Trains past home

The two neighbouring stations either side of your home, on the line you want alerts for.

Buses

Buses are off: enter a Bus Open Data Service API key under “API key” below to turn them on. These settings are saved for when they are.

Buses only appear when the map is zoomed in this far or closer, so they don't crowd the map at county scale.

Delays come from comparing each bus with its timetable. The region's timetables (about 300 MB) are downloaded weekly and cut down to the trips near home.

API key: Bus Open Data Service

For live buses. Register free, then copy the API key from your account settings.

Saved keys and passwords are never shown again: leave the box empty to keep the current one, or type a new one to replace it. New ones are checked before they're saved.
